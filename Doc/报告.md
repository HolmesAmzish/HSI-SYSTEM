# 第一章 需求分析

本项目旨在开发一套轻量化的高光谱农情监测系统，主要针对当前智慧农业在实际落地中面临的跨场景泛化能力弱与边缘侧算力受限两大痛点。高光谱图像虽然能提供丰富的物质属性信息，但由于不同农田间的传感器差异、环境光照变化以及复杂的背景干扰，传统监测模型在面对未见过的监测区域时往往性能骤降，且其庞大的参数量难以部署在无人机或嵌入式边缘设备上。本系统的研发初衷是利用先进的样本特异性低秩基混合技术，在极低参数规模下实现对复杂农情数据的自动化、高精度分类与分析，确保模型在异构环境下依然具备极强的鲁棒性。

在行业现状与对标方面，目前市场上的主流遥感处理软件及常规深度学习模型虽然功能全面，但在处理跨域数据时往往需要繁琐的人工干预或依赖目标域的大量标注数据进行重训练，且其模型体积通常在几十至几百兆字节之间，不符合农业现场实时作业的需求。本作品直接对标国际前沿的轻量化高光谱分类框架，通过引入自适应低秩自适应机制，在仅使用同类先进算法约百分之一参数量的条件下，实现了更优的领域泛化精度。这种极高的效能比使得本系统在与现有竞品的对比中，不仅能够有效应对传感器非线性畸变，更在嵌入式硬件的兼容性与部署成本上展现出显著优势。

本系统主要面向农业科研机构、智慧农场经营者及国土资源管理部门，提供从高光谱影像预处理、自动化作物种类识别到长势特征分析的一站式解决方案。其核心功能涵盖了复杂农业背景下的植被精准提取、多源异构数据下的自适应泛化分类以及基于轻量化架构的实时推理监测。在性能指标上，系统确保在Houston、Pavia及HyRANK等权威基准测试中展现出与顶尖大型模型相当的分类准确率，同时将推理延迟与内存占用压缩至极低水平，能够支持在无人机载处理器或卫星板载系统上进行高频次的农情分析，极大地提升了精准农业在实际生产环境中的响应速度与应用广度。

## 界面设计

本系统采用前后端分离架构，前端基于React与TypeScript开发，通过Vite构建工具实现高效的热更新与生产打包。界面设计遵循组件化与分层架构原则，自底向上划分为基础设施层、组件层、页面层与布局层。基础设施层通过React Context API实现主题管理，支持浅色、深色与跟随系统三种模式的动态切换；组件层基于Radix UI无头组件库封装基础交互元素，并针对高光谱分析场景定制开发文件上传、图像查看器、光谱统计图表、PCA点云可视化等业务组件。

系统采用侧边栏导航布局，通过React Router实现客户端路由管理，将高光谱图像管理、图像检视、光谱分析、地面真值管理等功能模块组织为清晰的信息架构。系统主界面如图1所示，展示了侧边栏导航与数据管理页面的整体布局。

## 数据库设计

系统采用 PostgreSQL 作为关系型数据库引擎，通过Spring Data JPA实现数据访问层的抽象。领域模型设计遵循领域驱动设计思想，核心实体包括高光谱图像（HyperspectralImage）、数据集（Dataset）、地面真值（GroundTruth）、分割标签（SegmentationLabel）与审计日志（AuditLog）。高光谱图像实体存储文件路径、处理状态、空间分辨率等元数据，通过外键关联所属数据集；数据集实体作为聚合根，管理一组相关图像的维度信息与可视化配置；地面真值实体存储地物分类标注，与高光谱图像建立多对一关联。

![数据图](assets/entity-diagrams.png)

实体关系通过JPA注解表达，采用数据库自增主键策略，多对一关系配置为懒加载以避免N+1查询问题。系统采用DTO模式解耦领域模型与外部接口，通过MapStruct实现Entity与DTO之间的转换。异步任务状态采用双写策略持久化：Redis用于实时状态查询与进度推送，PostgreSQL用于可靠的历史记录存储，结合 Spring Data 与Redis 集成实现读多写少数据的缓存优化。

## 关键算法

### ABSNet总体架构

![IMAGE|64](data:image/jpeg;base64...)

图 1 ABSNet总体架构

  

所提出的自适应秩光谱网络（ABSNet）旨在以极小的参数开销，从高光谱图像（HSI）中提取域不变特征表示。如图1所示，ABSNet通过一个四阶段的流水线处理输入图像块$Χ\in ℝ^{B×C\_{in}×P×P}$：(i)用于降低分辨率的分层起始阶段（stem stage）；(ii)用于光谱细化的通道重校准模块（CRB）；(iii)用于鲁棒特征嵌入的双分支Tokenizer（SSCT和DBMA）；以及(iv)用于全局上下文建模的轻量级标记融合单元（LTFU）。最终的类别逻辑值（logits）$z$是通过基于全局池化的线性分类器生成的。

  

### 层次化特征提取与再校准

  

高光谱图像面临着丰富的光谱信息与结构冗余之间固有的权衡。为了提取紧凑的域不变的特征表示，所提出的ABSNet采用了一种分层特征蒸馏流水线。初始阶段充当光谱-空间瓶颈，通过连续的步长卷积将高维输入$X$逐步映射到潜在特征空间$Y$中。这种分层下采样不仅扩大了感受野，还减轻了后续标记化的计算负担。

  

为了针对域敏感的光谱噪声进一步细化该表示，我们集成了一个通道重校准模块（CRB）。CRB背后的核心逻辑是显式地对通道间的依赖关系进行建模，并衰减在不同域之间表现出高方差的波段。令$U$表示由倒残差变换生成的中间特征。我们通过聚合全局空间上下文来导出一个逐通道重要性向量$s$：

  

$$\begin{array}{c}s=σ(G\_{re}(δ(G\_{re}(GAP(U)))))\#(1)\end{array}$$

  

$$\begin{array}{c}Y=(U⨀s)+ℋ(X\_{in})\#(2)\end{array}$$

  

其中$GAP(∙)$表示全局平均池化，且$G\_{re}$和$G\_{ex}$分别表示降维和升维投影。通过用$s$调制$U$，网络在冗余或嘈杂的光谱通道传播到标记器之前动态地将其抑制，从而确保嵌入的tokens专注于鲁棒的判别性特征。

  

### 双分支鲁棒标记化

  

在轻量级高光谱图像（HSI）分类中，一个关键的挑战是处理由光照变化或传感器特性引起的实例级光谱偏移。固定的线性投影通常缺乏适应此类非平稳分布的能力。为了解决这一问题，我们提出了一种双分支标记器，它将特征嵌入分解为一个稳定的空间分量和一个动态的自适应分量。

  

光谱-空间协同标记器（SSCT）：SSCT分支作为网络的结构锚点，旨在保持局部几何连贯性和光谱保真度。它采用了一种协同门控机制，其中空间特征$Y\_{spat}$由学习到的光谱注意力图$s\_{attn}$进行调制。标记的生成过程可公式化为：

  

$$\begin{array}{c}T\_{ssct}=P((Y\_{spat}⨀s\_{attn})+Y)\#(3)\end{array}$$

  

其中$P(∙)$表示到标记维度$d$的线性投影。这种残差门控设计确保了生成的标记在通过局部空间上下文得到增强的同时，保留了地物的基本光谱特性。

  

动态基混合自适应（DBMA）：为了在不引入标准动态网络巨大参数开销的情况下，捕获特定于样本的光谱差异，DBMA分支引入了一种基于流形的自适应机制。其核心假设是光谱畸变存在于一个低维流形上。因此，我们构建了一组M个共享的低秩基对$\left\{A\_{m},B\_{m}\right\}$，其中每个基对定义了一个秩一变换专家。对于每个输入实例，网络根据图像块的全局统计信息推断出一个混合系数向量$c$。这些系数被用于动态合成一个特定于实例的自适应矩阵$W\_{∆}^{(b)}$：

  

$$\begin{array}{c}W\_{∆}^{(b)}=\sum\_{m=1}^{M}c\_{m}^{(b)}(A\_{m}B\_{m})，c=Softmax(MLP(GAP(Y)))\#(4)\end{array}$$

  

$$\begin{array}{c}T\_{∆}=Y\_{flat}(W\_{∆}^{(b)})^{T}\#(5)\end{array}$$

  

此处，$Y\_{flat}$表示空间展平后的特征。项$A\_{m}B\_{m}$表示构成基矩阵的外积。通过对这些基进行线性组合，模型能够以严格受限的参数量来近似复杂的非线性光谱偏移。最终的标记表示是稳定流与自适应流的融合：

  

$$\begin{array}{c}T=Τ\_{ssct}+αT\_{∆}\#(6)\end{array}$$

  

其中$α=0.4$是一个固定的残差缩放因子。这种设计使得ABSNet能够通过SSCT维持稳定的决策边界，同时通过DBMA校正域差异。

  

### 序列标记融合与预测

  

为了高效地对长程依赖进行建模，轻量级标记融合单元（LTFU）将标记视为一个序列，并应用分阶段细化。与具有二次计算复杂度的标准Transformer不同，LTFU通过序列化的空间和通道混合操作来实现全局上下文建模：

  

$$\begin{array}{c}T\_{mid}=T+β∙ℱ\_{spat}(LN(T))\#(7)\end{array}$$

  

$$\begin{array}{c}T^{'}=T\_{mid}+β∙ℱ\_{chan}(LN(T\_{mid}))\#(8)\end{array}$$

  

其中，$F\_{spat}$利用大核卷积来传播空间信息，而$F\_{chan}$利用多层感知机（MLP）来细化通道间语义。缩放因子$β=0.5$稳定了这种轻量级结构中的信号流。最后，细化后的标记通过全局平均池化（GAP）进行聚合，形成紧凑的图像描述，该描述通过卷积分类器映射为类别逻辑值$z$：

  

$$\begin{array}{c}z=Flatten(W\_{cls}∗GAP(T^{'}))\#(9)\end{array}$$

  

这种架构确保了最终的分类是基于一种既经过局部细化又具备全局上下文的特征表示，从而以极小的计算开销实现了跨域的鲁棒性。

  

### 模型训练与优化策略

  

为了确保模型在有限的源域标签下能够实现稳定收敛并获得最优的泛化能力，本系统在模型训练与参数优化方面采取了以下核心策略：

  

数据增强与样本输入：模型的训练完全依赖于带有标签的源域样本。为了防止模型过拟合定式特征并提升鲁棒性，系统在输入端引入了数据增强机制，具体包括随机的水平/垂直翻转操作，以及增强幅度比为3的辐射增强。训练时的批处理大小设置为256。

  

优化器与超参数设置：模型整体训练周期设定为300个epoch。在反向传播优化方面，系统选用了Adam优化器，并将初始学习率设置为$10^{−2}$，以保障模型在复杂的高光谱特征空间中能够快速且稳定地寻找全局最优解。

  

损失函数：系统的监督信号完全由源域数据提供。模型采用负对数似然损失来计算分类误差并指导网络权重的更新，其数学公式定义如下：

  

$$\begin{array}{c}ℒ=−\frac{1}{N}\sum\_{i=1}^{N}log\hat{y}\_{i,y\_{i}}\#(10)\end{array}$$

  

其中，表示网络对第i个样本所属真实类别的预测概率。

  

在高光谱域泛化任务中，由于源域的标记像素极其有限，在源域上进行验证容易导致结果不稳定。因此，本系统采用了一种面向目标域的验证策略：在每个epoch的训练结束后，系统会在整个未标记的目标域上对模型进行评估。训练过程中会持续追踪并保留达到最高总体准确率（OA）的模型权重作为最终输出模型，从而最直接地反映和保留模型真正的跨域泛化性能。为保证结果的可复现性，所有训练过程均固定了随机种子并采用相同的数据划分方式。

### 参数分析

  

训练样本比例的影响：高光谱图像中像素级标注的稀缺性和高成本使得域泛化方法在有限监督下保持鲁棒性变得至关重要。为了研究这一特性，我们在保持验证方案不变的情况下，将用于训练的带标签源域像素比例从10%变化到100%。如图8所示，总体准确率（OA）、平均准确率（AA）和Kappa系数在低比例时表现出快速提升，并在所有三个数据集上在60%左右开始饱和。超过这一点后，边际收益显著减少，同时伴随着对标签噪声的敏感性增加以及对特定于源域的模式的轻微过拟合。80%的比例在不造成过多标注负担的情况下，始终能提供分类性能与跨域泛化能力之间的最佳权衡。因此，该比例被采纳为所有后续对比和消融实验的标准设置。

图 8 三个数据集上性能随训练样本比例的变化

  

学习率的影响：合适的学习率选择对于带有残差自适应组件的轻量级架构的稳定收敛至关重要。我们在相同的训练条件下，系统地评估了初始学习率在$\{10^{−1},5×10^{−2},10^{−2},5×10^{−3},10^{−3},10^{−4}\}$范围内的表现。图9中展示的结果表明，过高的学习率$(10^{−1}和5×10^{−2})$会导致严重的训练震荡和较差的目标域泛化性能，特别是在具有挑战性的HyRank数据集上。相反，过于保守的学习率$(\leq 10^{−3})$会导致在固定的300个epoch预算内收敛缓慢和欠拟合。$1×10^{−2}$的学习率始终能实现最快的收敛，同时在所有基准测试中产生最高的目标域OA，这证实了它对所提出的参数高效设计的适用性。因此，在研究的剩余部分中，该值被固定不变。

DBMA超参数的影响：动态基混合自适应（DBMA）模块的表达能力和泛化行为主要受两个超参数控制：共享基的数量$M\in \{1,2,4,8\}$和内在秩$r\in \{1,24,8\}$。我们在所有三个数据集上进行了全面的网格搜索。如图10所示，适中的配置$(M=2,r=1)$在自适应灵活性和正则化强度之间取得了最佳平衡，能够有效地补偿特定于实例的光谱偏移，而不会对源域的特异性过度拟合。当M或r增加超过这些值时，会引入过多的参数容量，导致目标域性能下降——这在域差异明显的Houston和HyRank数据集上尤为显著。最小配置$(M=2,r=1)$始终名列前茅，同时提供最高的参数效率。因此，该设置被选为所有剩余实验的默认设置，进一步验证了低秩约束在防止严重分布偏移下的过度自适应方面的有效性。

标记融合权重的影响：标量权重$α$控制着DBMA生成的补偿标记与SSCT分支产生的基础标记的相对贡献，从而控制着保持光谱保真度与激进的域偏移校正之间的权衡。我们对$α=\{0.1,0.2,...,0.9\}$进行了细粒度搜索。图11中的结果表明，跨数据集的一致性非常显著：性能在$α=0.4$附近急剧达到峰值，超过该值后，DBMA影响的进一步增加开始扭曲具有判别性的稳定光谱模式，特别是影响少数类（例如，Houston中的水体，HyRank中的稀疏植被）。相反，低于0.3的值提供的自适应强度不足，使得残余的域差异得不到解决。最佳的$α=0.4$有效地保持了来自SSCT的鲁棒空谱特征表示的主导地位，同时允许来自DBMA的有针对性的、特定于样本的校正——以最小的过度校正风险实现了卓越的泛化性能。该值在所有后续实验和最终模型中均被固定。

### 消融实验

  

为了定量验证每个提出组件的贡献与必要性，我们在相同的训练条件下（见表9），在Houston、Pavia和HyRank数据集上进行了全面的消融实验。移除通道重校准模块（CRB）始终会导致性能下降，这证实了它在早期抑制域敏感波段方面的核心作用。尽管单独添加SSCT在Houston数据集上导致了性能的轻微下降，这是因为在缺乏后续光谱校正的情况下，其强大的空间混合和通道重加权可能会无意中放大特定于源域的模式；然而，一旦与所提出的DBMA结合使用，SSCT通过有效保留在不同域之间基本保持不变的判别性光谱-空间连贯性，在所有数据集上都实现了持续且显著的性能提升。不过，最显著且最鲁棒的提升是由DBMA本身带来的，特别是在面临严重的域偏移时，这直接验证了其进行精确、参数高效的光谱自适应的能力。

# 第五章 安装及使用

  

## 环境要求

本系统采用前后端分离的微服务架构，部署环境需满足以下要求：操作系统支持 Windows 11、Linux（Ubuntu 22.04）；依赖服务包括 PostgreSQL 14+数据库与 Redis 缓存服务。

## 安装过程

**后端服务部署**：进入Server目录，复制敏感信息配置并填写

```bash
cp Server\src\main\resources\keys-example.properties Server\src\main\resources\keys.properties
```

配置数据库连接、Redis地址与共享存储路径，敏感信息写入keys.properties。可以不填写，直接通过**环境变量**让程序自动识别。

```properties
application.security.jwt.secret-key=${JWT_SECRET}

spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}

spring.data.redis.password=${REDIS_PASSWORD}
```

执行`./gradlew bootRun`启动开发服务器，或执行`./gradlew bootJar`构建生产JAR包后通过`java -jar`运行。

```bash
gradle bootRun
```

如果是 Windows 环境

```ps1
./gradle.bat bootRun
```

**推理模块部署**：进入Inference目录，首先需要进行基本设置，都是选填，端口或主机地址在程序中有默认值（localhost 与 6379），Redis 密码根据当前服务器是否有密码而顶

```env
REDIS_HOST=
REDIS_PORT=
REDIS_PASSWORD=
```

通过uv工具执行`uv sync`安装Python依赖，配置.env文件中的Redis与数据库连接信息，执行`uv run main.py`启动任务监听服务。

```bash
uv sync
uv run main.py
```

**前端模块部署**：进入Web目录，执行`npm install`安装依赖，开发模式下执行`npm run dev`启动Vite开发服务器，生产环境执行`npm run build`构建静态资源并部署至Nginx等Web服务器。

```bash
npm install
npm run dev
```

## 典型使用流程

用户通过浏览器访问前端界面，首先上传高光谱图像MAT文件，系统自动触发格式转换与元数据提取；随后可上传对应区域的地面真值标注文件，或直接使用系统提供的推理功能生成分类结果；在分析页面，用户可查看假彩色合成图像、光谱曲线统计以及PCA降维后的三维点云可视化，支持交互式探索与结果导出。
