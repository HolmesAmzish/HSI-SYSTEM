## 环境要求

本系统采用前后端分离的微服务架构，部署环境需满足以下要求：操作系统支持 Windows 11、Linux（Ubuntu 22.04）；依赖服务包括 PostgreSQL 14+数据库与 Redis 缓存服务。

## 安装过程

**后端服务部署**：进入Server目录，复制敏感信息配置并填写

```bash
cp Server\src\main\resources\keys-example.properties Server\src\main\resources\keys.properties
```

配置数据库连接、Redis地址与共享存储路径，敏感信息写入keys.properties。可以不填写，直接通过**环境变量**让程序自动识别。

```properties
application.security.jwt.secret-key=${JWT_SECRET}

spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}

spring.data.redis.password=${REDIS_PASSWORD}
```

执行`./gradlew bootRun`启动开发服务器，或执行`./gradlew bootJar`构建生产JAR包后通过`java -jar`运行。

```bash
gradle bootRun
```

如果是 Windows 环境

```ps1
./gradle.bat bootRun
```

**推理模块部署**：进入Inference目录，首先需要进行基本设置，都是选填，端口或主机地址在程序中有默认值（localhost 与 6379），Redis 密码根据当前服务器是否有密码而顶

```env
REDIS_HOST=
REDIS_PORT=
REDIS_PASSWORD=
```

通过uv工具执行`uv sync`安装Python依赖，配置.env文件中的Redis与数据库连接信息，执行`uv run main.py`启动任务监听服务。

```bash
uv sync
uv run main.py
```

**前端模块部署**：进入Web目录，执行`npm install`安装依赖，开发模式下执行`npm run dev`启动Vite开发服务器，生产环境执行`npm run build`构建静态资源并部署至Nginx等Web服务器。

```bash
npm install
npm run dev
```

## 典型使用流程

用户通过浏览器访问前端界面，首先上传高光谱图像MAT文件，系统自动触发格式转换与元数据提取；随后可上传对应区域的地面真值标注文件，或直接使用系统提供的推理功能生成分类结果；在分析页面，用户可查看假彩色合成图像、光谱曲线统计以及PCA降维后的三维点云可视化，支持交互式探索与结果导出。
